Doggy 173 - an SCP Exiter Breach mod

- Base game + original 173 texture: SCP - Containment Breach
  (Undertow Games / SCP-CB Community Preservation Project, CC BY-SA 3.0).
  The Doggy texture is a repaint of the original 173texture.jpg UV layout:
  warm fur tint, dog spots on the body, and a painted dog face (floppy ears,
  muzzle, nose, tongue) in the head region.
- Sounds are Doggy's own sounds, reused from Eric's Doggy Containment
  Breach audio library (public/audio, see that project's LICENSES.md):
  StoneDrag.ogg  <- growl-2 (looped, faded loop point)
  Rattle1.ogg    <- sniff
  Rattle2.ogg    <- creature-whine
  Rattle3.ogg    <- growl-1
  NeckSnap sounds are deliberately left stock. He is still 173.
- MODEL (v2 of this mod): GFX/npcs/173_2.b3d (+ GFX/map/173_2.b3d room prop)
  is a from-scratch sitting-dog mesh (2,149 verts / 3,276 tris) written
  directly in Blitz3D .b3d format by a Python generator - floppy ears,
  muzzle, nose, tongue, red collar, cream chest/paws, body spot, tail.
  Colours come from its own palette texture GFX/npcs/doggybody.jpg.
  The statue texture repaint above is kept for anything still using it.
- Size fix: the game scales 173 by scale / MeshDepth (Data/NPCs.ini).
  The dog's H/D is 1.129 (statue: 3.303), so Data/NPCs.ini in this mod
  overrides ONLY SCP-173's scale to 1.02 = same in-game height as stock.
  Speed and everything else fall back to stock per-key.
- Icon + loading screen art drawn for this mod.
